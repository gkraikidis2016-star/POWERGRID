ΣΗΜΑΝΤΙΚΟ:
Η κοινή online βάση δεδομένων δεν μπορεί να δημιουργηθεί μέσα από το ZIP μόνο.
Για πραγματικό συγχρονισμό μεταξύ διαφορετικών κινητών θα συνδεθεί σε backend (π.χ. Supabase/Firebase)
και θα αντικατασταθεί το demo login με ασφαλή authentication.

Επόμενο τεχνικό βήμα:
1. Δημιουργία δωρεάν backend project.
2. Πίνακες Workers, Attendance, Overtime, Requests.
3. Ρόλοι Admin/Worker.
4. Ασφαλές login.
5. Real-time ενημέρωση.
6. PWA → Android/iPhone και αργότερα stores.
